## Built for racing, not just sightseeing

Race across **12 courses in three four-race cups**, tackle opponents in multiple race formats, spend earned currency on upgrades and fight for the championship. The small screen doesn't mean small ambition: there are varied circuits, shifting positions, hazards, a pit/garage progression loop and several multiplayer ways to play.

| Game feature | What to expect |
|---|---|
| **Normal racing** | Traditional arcade racing against computer opponents |
| **Reverse racing** | Take the courses in the opposite direction |
| **Weapons racing** | Race with special pickups and extra track hazards |
| **Championships** | Three cups, four rounds each, cumulative standings and car upgrades |
| **Same-console two-player** | Two players share one NGPC in a quick head-to-head duel |
| **Link cable racing** | Host/Join sessions, races and four-race link cups using compatible consoles |
| **Time Attack** | Chase your best lap with traps on or off |
| **Four mini-games** | Cliff Brake, Bumper Drop, Maze Chase and Bomb Grid |
| **Records and QR** | Local bests plus an experimental time-based QR submission workflow |

Some courses and extra modes are unlocked through progression. The captures below include unlocked-mode preview states to show what is being developed.

## What's changed in v1.0.7?

The biggest focus is **smoother link racing**, without altering physics, scoring or the existing game content.

- Pipelined link updates and fixed three-refresh picture timing target **20 frames per second** for both link screens.
- Less HUD redraw work and other optimisations protect the game simulation's full speed.
- Solo racing has also received performance refinements.
- Music, saves, QR version 4 format, local records and gameplay rules remain as described in the supplied release notes.

**Test context:** the supplied developer measurements use the **NgpCraft Studio 4.3.2 emulator core**, not physical hardware. The report records roughly full game speed and 20 fps for tested link scenarios, but real-cable performance still needs validating. [Read the development notes](PROJECT_NOTES.md).

## Controls at a glance

| Context | Controls |
|---|---|
| Main race | **A** accelerate, **B** brake, **Left/Right** steer, **OPTION** pause |
| Championship menu | **Up/Down** select race mode, **Left/Right** select cup, **A** start |
| Options | **OPTION** from title screen |
| Same-console duel | Player 1 uses D-pad, Player 2 uses A/B; automatic acceleration |
| Link cable | **Options → Link Cable**, then choose HOST or JOIN |
| Records / QR | **Options → Records**, then choose the relevant time record and follow prompts |

See [PROJECT_NOTES.md](PROJECT_NOTES.md) for more detail and testing cautions.

Most frames were captured by compiling and running the package's **own C-source host renderer** at the NGPC's 160 × 152 resolution, then nearest-neighbour upscaled for legibility. The title graphic and four link-cup screens came directly from supplied screenshots/evidence. A host renderer is not a replacement for a photograph or capture of the ROM running on physical NGPC hardware.
